## 三、 人为物理依赖解耦准则

在 A2A 跨端协议与网络保活中，工程实现遵循**主备解耦**原则：

1. **第一通信主链路（局域网 / USB ADB Forward）**：
   - 依赖 PC 与手机的 USB/Wi-Fi ADB 调试隧道（端口 `8022`、`10022`、`9910`、`9911`）。
   - 该路径已通过 15 分钟息屏与断链 soak 测试（证据见 `con_hf/runs/2026-10-28_a2a_v1_2/LIVE_SOAK_15M.json`）。
   - **自动化测试与软件发布门禁以此为基础，不设人为交互卡点。**
2. **第二通信备用链路（异地专网 Tailscale）**：
   - 定位为**可选增强特性**（Optional WAN Extension）。
   - 未安装 Tailscale 时，`ops/a2a_preflight.ps1` 仅报告 `WARN` 保持 adb forward 活跃，严禁将其提升为硬性 `FAIL` 阻塞软件交付。
