## 第一章、 总体工程流向与三阶段施工总纲（Standard Engineering Workflow）

   * **核心定位**：先把“地基”打牢——统一单一事实源（SSOT）代码契约、建立双平面物理目录、固化 K40 算力防崩与长任务铁律、完成容器 R 4.5.3 与离线公共参考库底层验证。
   * **包含工作包**：
     * `WP-1.1`：全局单一事实源（SSOT）契约收口（20 条肿瘤黑名单、14 类数据格式白名单、`ledger.js` 四类路径合法根）。

2. **第二阶段：相关配套（Phase 2: Supporting Facilities —— 台账、脚手架、门禁、注册表与同步通道）**
   * **核心定位**：在稳固地基上搭建“脚手架、管道与守卫”——不动具体业务分析逻辑，先把 JSONL 台账与索引生成器、阶段感知桥接守卫、图级模板注册表、Sync 单向传输通道与远端原子同步工具全部配齐并跑通单测。

## 第二章、 第一阶段规范：基础落地（Phase 1: Foundation Landing）

### 2.1 “云-端”解耦四角色拓扑與三大执行铁律

#### 2.1.1 四角色单向拓扑契约
| 角色平面 | 监听/物理落点 | 允许行为 | 严禁行为（红线） |
| :--- | :--- | :--- | :--- |
| **1. 客户端（浏览器）** | 外网 / 局域网访问 `8080` | 提交建项表单与分片文件、勾选流程与图型模板、触发结果同步、浏览内置预览图与已推送的真实结果 | 严禁直接访问 `8787` 编排面或拉取服务端任何内部未公开状态 |
| **2. 客户门户（Portal）** | 本地 `8080` (`portal/serve.mjs`) | 接收客户输入落盘 `portal/inbox/`、维护 `sync_status`、响应 8787 出站拉取与结果推送、渲染示例图与真实结果 | **严禁主动发起向 8787 工作台的网络连接**；严禁读取 8787 内部目录 |
| **3. 编排面（Workbench）** | 本地 `127.0.0.1:8787` (`server/index.js` + `ops/sync_daemon.ps1`) | 仅监听本地环回；出站拉取 8080 `inbox` 待办；通过 SSH 派发任务至 K40；回搬产物至 `local_projects/`；打包并出站推送结果回 8080 | **严禁开启公网入站监听**；**严禁在本地 PC 运行任何 R/Python 生信计算进程** |
| **4. 算力面（Compute Node）** | 自备算力节点 (`ssh k40:8022` / `k40-ubuntu:10022`) + 备用节点池 | 在 `/mnt/ssd/bio_data/` 原生分区执行三线生信计算、产图与桥接校验 | 严禁主动对外发起业务连接；严禁写入 `/sdcard` 或 FUSE 模拟层 |

* **同机环回网络铁律（纠偏条款）**：`8787` 编排面与 `8080` 门户同机通信全部走 `127.0.0.1`，必须显式设置 `NO_PROXY=127.0.0.1,localhost`，**严禁注入外网代理 `127.0.0.1:7890`**（外网代理仅用于容器或宿主访问外部公共库，同机环回属强制豁免范围）。

#### 2.1.2 三大不可逾越的执行铁律
1. **铁律一：非肿瘤、非免疫浸润专精原则（20 条黑名单 SSOT）**
   * 全流程专精非肿瘤领域（心脑血管、神经退行、代谢、纤维化、自身免疫、发育等），严禁主动加入临床生存预后、肿瘤免疫浸润、药物敏感性预测等肿瘤专属内容。
   * **20 条黑名单规格正本**（单一事实源：`BioanalysDesktop/server/tumor_blacklist.js`，2026-10-21 二次裁定定稿）：
     * **英文 16 条**：`cancer`、`tumor`、`tumour`、`carcinoma`、`glioma`、`sarcoma`、`lymphoma`、`leukemia`、`leukaemia`、`melanoma`、`immune infiltration`（正则 `immune\s*infiltration`）、`immune checkpoint`（正则 `immune\s*checkpoint`）、`PD-L1`（正则 `(?<![A-Za-z0-9])PD-?L1(?![0-9])`）、`PD-1`（正则 `(?<![A-Za-z0-9])PD-?1(?![0-9])`）、`CTLA-4`（正则 `CTLA-?4`）、`oncogene`。
     * **中文 4 条**：`肿瘤`、`癌`、`免疫浸润`、`免疫检查点`。
     * **匹配规则**：英文忽略大小写，中英文按子串匹配；唯独 `PD-L1` 与 `PD-1` 强制带左右字符边界，防止误伤 `GPD1`、`SLC40A1` 等合法非肿瘤基因符号。
2. **铁律二：三条平行分析线物理与逻辑硬隔离原则**
   * **线 1**：GEO Bulk 线（`line1_bulk`）；**线 2**：单细胞转录组 + 虚拟敲除线（`line2_scrna`）；**线 3**：单细胞空间转录组 + 虚拟敲除线（`line3_spatial`）。
   * **隔离红线**：三条线物理目录硬隔离，不互相取参考（如严禁从 Line 2 提取单细胞数据放进公共库供 Line 3 反卷积使用）、不合并数据集、不跨线验证。**虚拟敲除绝不是第四条独立线**，而是 Line 2（第 10 步）和 Line 3（第 9 步）各自的末端模块。
   * **图模板跨线隔离细则**：图型定义（画法、风格、依赖）、`adapt_vars` 字段声明与内置 `_verified.png` 预览图可跨线共享；但**表达矩阵、分组表、填入 `adapt_vars` 的具体项目数值及产出的真实图件绝不跨线**。
3. **铁律三：R / Python 线内最优分工、阶段感知桥接与 DEG/DR 物理区分原则**
   * 固定全局随机种子 `seed = 20261013`；严格控制线内语言切换次数（Line 1 切换 1 次；Line 2 切换 2 次；Line 3 全 Python 0 次切换）。
   * 每次跨语言转换必须通过**桥接四项断言检查点**（① 基因名 Symbol 完整性、② 矩阵行列方向与稀疏性、③ 细胞 Barcode 顺序、④ 降维/空间坐标保留）。
   * **DEG 与 DR Genes 严禁混写**：差异表达基因（DEG，转录本丰度变化）与虚拟敲除差异调控基因（DR Genes，调控网络拓扑微扰）在文件命名、表格、图件角标（强制带 `[Virtual KO Perturbation - DR Genes]`）与解读文本中必须物理隔离。

### 3.2 任务提交三道闸、阶段感知桥接与上传硬配额配套（`WP-2.2`）

1. **去注释双语识别（`BioanalysDesktop/server/task.js`）**：
   * `inspectBridgeNeed(scriptContent)` 必须先调用 `stripShellAndCodeComments` 剥离全部 `#` 纯注释行与行尾注释（仅保留 `#!` shebang），再正则检测 `Rscript`/`R -e` 与 `python3?`/`pySCENIC`，彻底根治注释文字引发的假阳性桥接拦截。
2. **阶段感知桥接引擎（`ops/verify_bridge_checkpoint.py` & `src/bridge_guard.sh`）**：
   * 支持 `--stage {pre-dimred,post-dimred}`（默认 `post-dimred`）。当 `.h5ad` 无 `X_pca`/`X_umap`/`spatial` 时：`post-dimred` 直接判 `[BRIDGE FAIL]` 退出码 `1`；若确系降维前早期矩阵交互并显式传入 `--stage pre-dimred`，则输出 `[BRIDGE WARN]` 并以退出码 `0` 合法放行。
   * `src/bridge_guard.sh` 执行顺序强制为**本机优先（`MODE=local`）、SSH 兜底**：在容器内直接本机调用 `verify_bridge_checkpoint.py`，非 0 退出立即中止母版。
3. **分片上传 20GiB 原子预留硬闸门（`shared/upload_session.mjs` + `server/upload.js`）**：
   * 4MB 分片，基于「项目 + 归属线 + 文件名 + 大小 + mtime」确定性派生 `uploadId`。
   * `POST /api/upload/init` 将声明的 `fileSize` 写入会话元数据 `reservedBytes` 进行原子预留；超 20GiB 配额时按 mtime 淘汰非活跃会话（10 分钟内活跃会话受保护），仍超限回 `507 Insufficient Storage`。
   * `POST /api/upload/chunk` 写盘前强制校验 `receivedBytes + chunk.length <= reservedBytes`，超限立即回 `413` 阻断；四个上传端点错误响应体统一为 `{ok: false, error}`。
