## 一、这个基准证明了什么，没证明什么

**证明了**：同一套母版代码在 11.5GB 手机上，能从原始 GEO 数据一路走到空间基因定位，每一步都有自校验、台账与内存硬顶。三条线（bulk / snRNA / Visium）互不干扰，跨线数据只能通过显式落盘的中间产物传递。

**没证明**：任何一条线的生物学结论都不能作为疾病机制证据。原因分别写在下面各章。

## 二、Line 1（bulk）：差异表达实为跨队列比较

### 2.1 数据事实

DCM 58 例是新鲜右室间隔活检，Ctrl 12 例是重新对齐的历史 GSE11625 系列。两批的建库时间、处理流程、测序批次都不同。

### 2.2 判定的核心证据

- 43,098 个基因里 **11,841 个（27%）在一组中 >=95% 为零**（单侧沉默），典型形态是技术性非编码基因与低检出基因；
- 留一交叉验证 **AUC = 1.000**。

**AUC 完美不是好消息**：它说明模型区分的是「哪一批样本」，不是「有没有病」。

### 2.3 处置方式（三表并存，不做 ComBat）

| 表 | 显著数 | 说明 |
|---|---|---|
| `deg_limma` 原始表 | 按阈值 | 保持行数兼容，不动 |
| `processed_sexadj/` | 3,603 | 加性别协变量的 OLS：`y ~ 1 + is_DCM + is_male`，BH 校正 |
| `deg_*_cohortfiltered.tsv` | 2,796 | 剔除单侧沉默/技术性/低检出 |

**为什么不做 ComBat**：当分组与批次完全共线时，任何批次校正都会在抹掉批次的同时抹掉疾病信号。这个队列差异本身就是解释的一部分，掩盖它等于自欺。

### 2.4 靶点

Top5 = **ATM, RPL7, ANKRD36C, UBN2, INO80D**。

只有 **ATM** 同时被 WGCNA hub（20 个）与 PPI hub（200 个）支持，且两组检出率都是 100%。
RPL7 是核糖体蛋白、ANKRD36C 是灵长类特异的着丝粒周旁系同源基因家族，两者在队列过滤后降级。

## 三、Line 2（snRNA）：走到签名导出全链

### 3.1 流程数字

| 步骤 | 结果 |
|---|---|
| 原始 | 77,436 细胞 x 33,939 基因，10 个 10x 样本（DCM 4 / Fetal 3 / Non-diseased 3） |
| QC | 保留 74,883（nFeature 200-6,000、pct_mt < 20、去双细胞） |
| HVG | 2,000（seurat 方法），基因总数 29,327 |
| Harmony | 10 批次，201 秒，供体混合熵 0.380 -> 0.773（+0.393） |
| 聚类 | 32 个 |
| 注释 | 10 类：心肌 30,771 / 成纤维 20,608 / 内皮 8,271 / 巨噬 5,781 / 周细胞 4,589 / 平滑肌 1,553 / T 1,493 / 施万 1,240 / B 135 / 未知 442（0.6%） |
| DEG | 263,943 行，12,561 显著；伪影筛查后 2,585（207 个泛细胞类型可疑） |
| LIANA | 36 万+ LR 对，1,485 细胞，覆盖 0.844 |
| 签名 | 9 类细胞类型均值表 5.07MB |

### 3.2 注释核验回执（10 类 x 42 marker）

**9 个有 marker 的细胞类型，自身 canonical marker 均值全部高于其它类型最高值（9/9 pass）。**

施万细胞专项（心脏样本 1,240 个、占 1.65%，占比偏高，逐基因核对）：

| marker | 施万 | 其它最高 | 最高的是谁 |
|---|---|---|---|
| PLP1 | **48.8%** | 3.2% | fibroblast |
| MPZ | **41.4%** | 1.8% | pericyte |
| S100B | **39.4%** | 1.4% | macrophage |
| NRXN1 | 99.4% | 20.0% | macrophage |
| MBP | 9.1% | **54.5%** | T_cell |

三个髓鞘/施万特异基因在施万里 39-49%、其它类型只有 1-3%（相对富集 13-28 倍），
**判定：1,240 个细胞是真实的心脏神经嵴施万群，不是串味。** 标签保留。

### 3.3 两个必须写进母版注释规范的反直觉现象

**现象一：TTN（肌联蛋白）在平滑肌/巨噬背景里高达 88%。**

TTN 是 10 万 bp 级超长转录本，背景检出天然高。用它做心肌 marker 会把心肌的判别力拉平：
第一版核验脚本用「自身均值 vs 其它均值」，心肌 79.9% vs 巨噬 81.6%，判成 review_needed。

| marker | 心肌 | 其它最高 |
|---|---|---|
| TNNT2 | 96.8% | 35.5% |
| MYH7 | 91.7% | 39.1% |
| ACTC1 | 90.7% | 30.0% |
| **TTN** | 99.2% | **88.0%** |

去掉 TTN：心肌 76.1% vs 其它最高 26.3%。**规范：超长转录本不作单一 marker 的判别依据。**

**现象二：MBP 方向反了（施万 9.1% vs T 细胞 54.5%）。**

与施万标签无关，属探针/参考注释问题。**规范：单个 marker 反向不足以否定细胞类型，需看同族多个基因的一致性。**

### 3.4 元数据以 GEO soft 为准

GPL24676：DCM1 男 / DCM2-4 女（5-10 岁），Fetal1-2 男 / Fetal3 女（19-20 周），
GSM5606413-15 的 GEO 标题是 `Non-diseased1-3`（4-14 岁），压缩包内文件名写的是 `Young1-3`。
两个名字都保留（`donor` 与 `geo_title`），报告以 GEO 为准。

## 四、Line 3（Visium）：只描述不推断

### 4.1 数据事实

三个样本**全部为雄性**，品系 "hybrid of C57BL/6 and ICR"，同一张玻片 `V11Y10-334` 的 A1/C1/D1 区域。
A_Ctrl 与 D_Ctrl_HF 共享基因型 `Tcf21iCre/R26 tdTomato`（干净的主对比），C_TTg_HF 额外带 `MGTH2A`（Gata4）。
探针集**不含 chrMT 基因**，所以 pct_mito 恒为 0。

### 4.2 流程与结果

| 步骤 | 结果 |
|---|---|
| ingest | 3 切片、14,976 spots、19,465 基因（跨样本基因宇宙完全同序，union=intersection） |
| QC | 保留 7,078 spots（A_Ctrl 1,935 / C_TTg_HF 2,157 / D_Ctrl_HF 2,986） |
| 空间域 | 每切片 4-8 个域；marker 合理（Myh7/Nppa/Ankrd1/Fabp4/Pdk4） |
| Moran's I | 最高 Acta1 0.656、Myh6 0.585、Lrtm1 0.572，三样本一致 |
| NNLS 解卷积 | 7,078/7,078 全部求解；跨物种匹配 14,678/29,317 = 50.1% |
| 靶基因定位 | ATM、UBN2、INO80D 在小鼠中找到；RPL7、ANKRD36C **如实报告缺失** |

### 4.3 统计边界（写死）

**主对比 n=1 vs 1。任何「疾病 vs 对照」的空间差异只能作描述性陈述，禁止跨切片 p 值推断。**

理由：Visium 在 n=1/组时，把成千上万个 spot 当独立样本做组间假设检验属于经典的伪重复（pseudoreplication）。保留三切片用于展示空间域、解卷积与 Moran's I 是合理的，因为它们描述的是**组织内空间结构**，不是组间差异。

### 4.4 跨物种诚实缺失是高价值阴性证据

人类 ANKRD36C 属于灵长类特异扩增的着丝粒周旁系同源基因家族，**小鼠基因组中本来就没有直系同源物**（即使引入联网 ortholog 表也是 None）。RPL7 在小鼠中的同名基因也未检出。
而 ATM / UBN2 / INO80D 被精准检出并完成空间定位，这恰好证明跨线筛选漏斗是客观的：没有为了「凑齐五个靶点」而伪造匹配。

## 五、跨线整合链

| L1 靶点 | L1 证据 | L3 空间定位 |
|---|---|---|
| **ATM** | WGCNA hub + PPI hub 双重支持，两组 100% 检出 | 215 spots，mean 0.026（表达量低） |
| RPL7 | 核糖体蛋白，队列过滤后降级 | 小鼠中无同名基因，如实缺失 |
| ANKRD36C | 灵长类特异，队列过滤后降级 | 小鼠中缺失（物种事实，非技术失败） |
| UBN2 | WGCNA hub | 1,336 spots，mean 0.171 |
| INO80D | WGCNA hub | 2,170 spots，mean 0.295（检出最广） |

**这条链能说明**：流程可以把 bulk 筛出的候选一路推到空间落点，并如实报告每一步的缺失与不确定。

**不能说明**：L1 差异大部分是队列差异；L3 主对比 n=1 vs 1；跨物种只有大写同名匹配（50.1%），无正式 ortholog 表；L2 标签是自动打分 + marker 核验，未做逐细胞人工标注。

## 六、本轮修掉的框架级缺陷

| 缺陷 | 根因 | 修复 | 证据 |
|---|---|---|---|
| LIANA 把手机打崩 | anndata backed 子集物化时整层读 layers（nnz 2.1 亿，单 indices 802 MiB） | h5_rows 按行区间读 CSR | RSS 9,063MB -> 792MB |
| 母版 normalize OOM | 同一根因 | 分块就地标准化（BLOCK_ROWS=4000） | 74,883 细胞跑通 |
| L3 ingest 基因 ID 校验失败 | scanpy 把 var_names 换成 symbol 并加后缀 | 核对改用 var['gene_ids'] | 三切片通过 |
| L3 ingest 误判非整数计数 | scanpy 把 10x int32 转成 float32 | 判值不判 dtype，再显式转 int32 | 通过 |
| L3 QC 拒绝输入 | ingest 读了 lowres 图却没写 uns['spatial'] | 补齐 scanpy 空间容器 | 14,976 -> 7,078 |
| domains/autocorr 依赖 squidpy | aarch64 装不上；装上后 1.8.3 又删了 morans_i/gearys_c | 自实现 cKDTree 建图 + 分块 Moran/Geary | 22.5 秒，解析解单测 9/9 |

| K40 脚本双向漂移 | 仓库与真机各自被改，单向覆盖会丢东西 | 同源门禁双向硬阻断 + 11 野生归档 | 57 脚本逐字节一致 |
