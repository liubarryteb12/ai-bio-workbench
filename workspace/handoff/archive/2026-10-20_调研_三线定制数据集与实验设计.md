## 一、调研报告

### 1.1 选型标准

按工作台既有流水线的硬约束反推数据集要求：

| 约束来源 | 对数据集的要求 |
|---|---|
| line1 `prep_matrix`（series matrix + GPL / counts 双模式） | 芯片数据优先（series matrix + GPL 注释齐全），或规整 counts |
| line1 `external_validation`（default 项目因无第二数据集被阻塞） | **必须有独立验证集**（第二个 GSE） |
| line2 `ingest_counts` 现有三分流（tar/soft/grouping） | 最好 counts 级公开产物；新格式须可探针定性 |
| line3 `ingest_spatial` 十项自校验（CSC 矩阵 / positions / scalefactors / 图像） | 必须是 10x Visium 逐样本 Space Ranger 标准产物，**有 disease vs control 两组多样本**（组检验步骤才有意义） |
| 算力端 5GB 单进程内存硬约束 | 数据量适中；scRNA ≤3 万细胞/单会话分片 |
| 算力节点存储 | RAW.tar 合计可控（现链路 226G/190G avail，单 tar ≤7GB 可承受） |
| 主题 | 非肿瘤、非免疫；代谢性/慢性病优先 |

### 1.2 主题确定：糖尿病肾病（DKD / DN）

理由：非肿瘤非免疫；GEO 挖掘文献极多（实验设计有成熟范式可对照）；同时存在芯片、单核、空间三层公开数据；与既有项目（银屑病 default、缺血性卒中 PRJ_20261019）无主题冲突。

### 1.4 结论

三条线各选定一套主数据集，全部通过 GEO 页面或多篇独立文献核实（明细见各线设计）。line1+line2 主题联动（DKD），line3 独立主题（生殖医学 RIF）——若用户要求三线同主题，line3 可换 GSE261545，但 1 样本无对照，组级分析空转，**不推荐**。

## 二、三线实验设计方案

### 2.1 line1_bulk —— DKD 肾小球芯片常规挖掘

**数据集（datasets 契约可直接落 portal 表单）**

| 角色 | GSE | GPL | 平台 | 样本 | 核实 |
|---|---|---|---|---|---|
| train | **GSE30528** | GPL571 | Affymetrix HG-U133A 2.0 | 9 DN vs 13 control（肾小球显微切割） | `[GEO直核]`（SuperSeries GSE30122，22 样本，TAR of CEL 45.5MB） |
| validation | **GSE104948** | GPL22945（另有 GPL24120 二平台） | Affymetrix HG-U133 Plus 2.0 | 7 DN vs 18 control | `[文献一致]`（≥4 篇） |
| validation | **GSE96804** | GPL17586 | Affymetrix HTA 2.0（外显子阵列） | 41 DN vs 20 control | `[文献一致]`（4 篇）+ OmicsDI 收录 |

**实验设计**

- 科学问题：DN 肾小球 vs 对照的差异表达基因、hub 基因与诊断模型。
- 对比对：DN vs Control（单对比对；GSE30529 小管区室 10 vs 12 可作可选探索，不进主链）。
- 归一化：各 GSE 内部独立 RMA/limma 流程后合并；跨数据集批次效应按既有 `sva`/`removeBatchEffect` 思路处理并在 PCA 复核（三篇文献均验证过该合并路径可行）。
- DEG：limma，**固定阈值** adj p<0.05 且 |log2FC|>1，不随结果调整（line1 既有纪律）。
- 下游：GO BP/CC/MF + KEGG 富集、WGCNA（22 样本，功率有限如实报告）、PPI、LASSO/RFE/单因素三法 hub 筛选、诊断模型。
- **外部验证（本次设计解锁 default 项目未做的步骤）**：LASSO/诊断模型在 GSE104948 与 GSE96804 上独立算 AUC，validation_type=external。
- 统计口径：9v13 小样本，精确置换/固定阈值，结论措辞降级为探索性。

**流程适配清单（line1 13 步）**

| 步骤 | 适配 |
|---|---|
| prep_matrix | 无需改：series matrix + GPL 路径现成。**注意 GPL571≠U133 Plus2**，探针→symbol 映射不能用已装 hgu133plus2.db，走 prep_matrix 既有的 GPL gene-assignment 列映射（已验证机制）；GPL22945 样本可复用 hgu133plus2.db |
| deg_limma / qc / pca / wgcna / ppi / ml_hub | 直接可用 |
| enrichment_bulk | 无需改（GSEA 离线 GMT）；KEGG 在线步保留断网跳过逻辑 |
| external_validation | **首次真跑**：validation_type 从 internal_holdout_approximation 换成真外部数据集，报告模板同步 |
| 整合去批次（步骤 3） | 用 GSE104948 与训练集合并即解锁（default 项目此项受阻塞） |

### 2.2 line2_scrna —— DKD 早期人肾 snRNA-seq

**数据集**：**GSE131882**（Wilson/Humphreys，PNAS 2019）`[GEO直核]`

- 3 control + 3 early DN（肾切除非瘤组织皮质），snRNA-seq（10x 5' v1，NovaSeq 6000，GPL24676），23,980 核通过质控，GRCh38。
- 公开产物：`GSE131882_RAW.tar` 1.4GB = **逐样本 zUMIs dgecounts RDS** + soft 元数据；SRA 有 raw fastq（不取，算力不必要）。
- 备选：GSE211785 scRNA 子集（16 对照 + 13 病变，合并 counts RDS + metadata txt，raw 未提供）——功率更好，但元数据字段与批次结构需探针定性；列为第二阶段升级项。

**实验设计**

- 科学问题：早期 DN 的细胞类型图谱与细胞类型特异性反应（离子转运/血管生成/免疫激活是论文主线索，可与 hub 基因联动）。
- 分组：`disease state`（diabetic vs control），6 donor 即 6 batch → Harmony 校正（复用线内既有 integrate_harmony）。
- 混杂如实记录：年龄 52-74、性别、eGFR 无组间差异（论文口径）；n=3v3 组检验全部走精确置换 + min 细胞数门槛（沿用既有统计纪律）。
- 虚拟敲除基因：**不预设**，按线内证据（marker/HVG/组间 DEG）产生候选后由用户确认——沿用 default 项目选 TNF 时的口径纪律。

**流程适配清单（line2 22 步）**

| 环节 | 适配 |
|---|---|
| ingest_counts | **需新增 RDS 输入分支**：R 侧（容器 R 4.3.3 + Matrix 已装）先把 zUMIs RDS 转 mtx.gz + metadata tsv（zUMIs RDS 是嵌套 list，结构须先探针定性），再进现有 Python ingest；或评估 pyreadr 纯 Python 读。**先探针后动工** |
| qc_cells | 阈值重定：snRNA 的 nCount/nFeature 分布与 scRNA 不同、线粒体比例天然更低、无 ERCC——用三轮探针定稿（沿用 default 项目做法），不照抄论文固定阈值 |
| 其余 20 步 | normalize/harmony/cluster/annotate（肾细胞类型 marker 集需新配）/pseudotime/通讯/富集/GSVA/SCENIC（基因空间受 5GB 约束，N_GENES 从 5000 起探）/KO/DR 汇总 | 
| 内存 | 23,980 核全基因 <30GB 矩阵量级，但单进程仍须分片 ≤5GB（既有硬约束） |

### 2.3 line3_spatial —— RIF 子宫内膜 Visium

**数据集**：**GSE287278**（Zhang et al., Sci Data 2025）`[GEO直核]`

- 8 样本 = 4 CTR（正常育龄期）vs 4 RIF（反复植入失败），分泌中期子宫内膜，10x Visium，GPL24676；合计 10,131 高质量 spots，中位检出基因 3,156；7 个细胞 niche。
- 公开产物：`GSE287278_RAW.tar` 内逐样本 `GSM*.tar.gz` → 解包为 `CTR*_processed_data/` 标准 Space Ranger 结构（filtered matrix + spatial/ 图像 + scalefactors）。
- 论文解卷积用了外部公共 scRNA 参考——与本线解卷积规则兼容（**只允许 public_references/ 或线内数据，仍不得用 line2**；DKD 肾参考与子宫内膜本身也不匹配）。

**实验设计**

- 科学问题：RIF 子宫内膜的空间结构/niche 组成改变；与线1/线2独立，不做跨线引用。
- 对比对：RIF vs CTR（4v4，C(8,4)=70 全枚举精确置换，既有统计口径直接支持）。
- 空间域、Moran's I、邻域共现、区域组成、空间通讯、目标基因定位、虚拟敲除：全链路 17 步可跑（解卷积按既有决策维持跳过，参考来源待用户决策）。
- KO 基因：线内 marker 证据出来后定（default 项目 Spp1 口径同款）。

**流程适配清单（line3 17 步）**

| 环节 | 适配 |
|---|---|
| ingest_spatial | **需支持两层嵌套 tar**（RAW.tar → GSM*.tar.gz → processed_data）；现有四分流输入契约扩一支。物种单一（人），比 default 双物种更简单。图像/scalefactors 档位（是否 CytAssist FFPE）上数后探针定性 |
| qc_spots | 阈值重定（内膜组织 spot 密度与肝不同），三轮探针 |
| spatial_domains 以后 | 无需改 |
| 解卷积 | 维持跳过（参考来源须用户提供或选公共子宫内膜 scRNA，另议） |

## 2.5 与《非肿瘤·非免疫 GEO 生信课题分析规范》的对齐（2026-10-20 补）

本实验设计已按 `docs/geo_mining_sop_v1.md`（同日落盘）对齐，对齐结论：

1. **Stage 8 外部验证**：本设计 train/validation 三数据集结构正是 SOP Stage 8 的"独立外部验证"要求；GSE96804（41v20）作主外部验证集，GSE104948 作次级验证，无外部验证则结论上限必须降级为"候选标志物"——本设计天然满足。
2. **C1 三重判据的落地警示（重要）**：Woromiecka 系 DKD 文献的已知 hub 基因多为 C1QA/C1QB/CD53/CCR2/CD163 等**免疫相关基因**。按 SOP Stage 5"偏免疫警示"，本课题的结论主轴必须在设计阶段就锁定**足细胞/系膜细胞/ECM 重塑/代谢轴**，DEG 出现免疫信号富集时按 SOP 处理（重新界定科学问题，不顺着免疫通路滑下去），不得把免疫浸润作为核心论证。
3. **Stage 3 分层 raw 规则对本设计的应用**：GSE30528 raw CEL（45.5MB）→ raw 优先路线，前提是容器 oligo/affy 可用（**未验证**，动工前探针）；GSE96804（外显子阵列）→ 处理级 series matrix + 声明处理层级；GSE104948 按平台探针定性后定。
4. **Stage 7/8 缺口**：SOP 要求的四算法交集（缺 SVM-RFE/XGBoost）与 Nomogram/校准/DCA 为工作台既有缺口（见 SOP 附录 A），新项目动工前由用户拍板是否补齐；未补齐前结论措辞按"候选 hub 基因"降级。

## 三、执行顺序建议

1. **line1 最先**（改动最小：prep_matrix 现成、external_validation 解锁、三个 GSE 体积小）。
2. **line3 次之**（仅 ingest 嵌套 tar 一个适配点，8 样本算力压力小）。
3. **line2 最后**（RDS 探针 + ingest 分支 + QC 阈值重定，工作量最大）。
4. 每线动工前：探针定性 → 最小改动 → 回读验证 → 界面验收 → 07 回搬（既有纪律，不再复述）。
