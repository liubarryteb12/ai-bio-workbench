## 一、三条生信分析流水线总览

工作台内置三条全自动、工业级的生信分析流水线，业务上覆盖临床科研最核心的转录组挖掘场景。三线在数据存储、运行环境、结果目录上实施物理隔离：

| 流水线标识 | 流水线全称 | 核心业务场景 | 母版脚本数 | 编排 Mod 数 | 主导开发语言 | 硬件内存峰值 |
|---|---|---|---|---|---|---|
| `line1_bulk` | GEO Bulk 转录组常规挖掘 | 疾病微阵列/RNA-seq 差异基因、WGCNA 模块共表达、机器学习标志物筛选 (LASSO/RF/SVM)、预后生存与列线图 | 15 个 | 11 个 | R (DESeq2/limma) + Python (scikit-learn) | $\le 1.8\text{ GB}$ |
| `line2_scrna` | 单细胞转录组 + 虚拟敲除 | 10x 单细胞数据质控、Harmony 多样本整合、亚型自动注释、细胞通讯 (CellChat/CellPhoneDB)、scTenifoldKnk 虚拟基因敲除、SCENIC 转录因子调控网络 | 22 个 | 21 个 | Python (Scanpy) + R (Seurat/scTenifoldKnk) | $\le 4.5\text{ GB}$ |
| `line3_spatial` | 空间转录组 + 空间虚拟敲除 | 10x Visium 空间切片质控、晶格标定、空间自相关 (Moran I)、BANKSY 空间聚类、轻量 NNLS 空间解卷积、空间虚拟敲除 (scTenifoldKnk-Spatial) | 17 个 | 17 个 | Python (Scanpy/Squidpy) + R | $\le 3.8\text{ GB}$ |
| **全仓汇总** | **三线贯通** | **涵盖常规转录组、单细胞、空间多组学联立分析** | **57 个脚本** | **49 个核心 Mod** | **R 4.5.3 + Python 3.10** | **严格控制在 7680 MB 容器配额内** |

> **57 个脚本说明**：15 (Bulk) + 22 (scRNA) + 17 (Spatial) = 54 个分析母版，加上 3 个跨步骤底层支持脚本（`line1_bulk/scripts/probe_env` 探活脚本、`line2_scrna/scripts/h5_rows.py` h5 元数据解析器、`line3_spatial/scripts/spatial_stats.py` 空间统计辅助库），共计 57 个标准脚本。在 K40 远端容器 `/mnt/ssd/bio_data/bin/` 保持 100% 逐字节同源。

## 三、算力与内存红线（硬件受限运行面硬约束）

### 1. 核心物理约束
- **7680 MB 绝对配额**：物理机总内存 8GB，Termux 容器分配配额上限严格设定为 **7680 MB**，留 512 MB 兜底系统内核防 Panic；
- **纯 ARM CPU 架构**：K40 骁龙 870 缺乏独立 GPU 显存，所有生信计算依赖 ARM64 矢量指令集。

### 2. 空间解卷积算法禁令（REJ-006）
- **硬约束**：解卷积算法**严格限定为轻量 `scipy.optimize.nnls`（非负最小二乘）**，单步内存消耗 $\le 2.2\text{ GB}$；
- **严厉禁令**：**严禁在生产流水线上引入 `cell2location`、`Stereoscope`、`RCTD` 等深度学习或重型马尔可夫链回归算法**；
- **违规后果**：上述重型算法在 8GB 设备上会导致 Linux OOM 杀手触发（Exit 137），或者因持续高负载导致芯片超过 95°C 发生降频死锁；
- **零算力精度补偿路线**：
  1. **输入端 Marker 严格提纯**：每个单细胞亚型只取特异性最高的前 **Top 20** 基因（过滤掉线粒体、核糖体等管家基因噪音）；
  2. **输出端极低丰度硬截断**：解卷积输出丰度矩阵中，低于 **0.05 (5%)** 的低频噪音一律硬置零归一化，既消灭伪影，又大幅降低下游稀疏矩阵计算内存。

## 四、跨语言桥接四项严格校验 (`checkpoint_*_bridge.py`)

流水线中存在 R 与 Python 相互交接的节点。为防止格式漂移与静默截断，桥接节点必须通过 `checkpoint_r_to_py_bridge.py` 与 `checkpoint_py_to_r_bridge.py` 验证：
1. **行数与维度校验**：交接矩阵行数必须完全恒等；
2. **非空与缺失值校验**：关键特征列缺失率不得超过 0.1%，空矩阵直接阻断；
3. **列名规范化校验**：列名不得包含空格、特殊控制字符，基因 Symbol 自动归一化为官方 HGNC/MGI 符号；
4. **数值域范围校验**：表达量必须是非负数，log 转换后必须在合法浮点区间内。
