## 二、商业机密级交付报告脱敏红线

工作台生产的所有客户报告必须满足严格的商业机密脱敏要求。

### 1. 核心脱敏原则
- **读者只关心生物学结论**：报告正文、图表附注与结论段落中，只写生物学统计量、分组效应、显著性 P 值、基因表达倍数变化；
- **零基础设施信息泄露**：严禁出现内部代码路径、开发机器名、执行硬件名称或底层容器环境。

### 2. 违规词黑名单库
以下词汇一旦出现在导出的报告文本中，契约测试将直接报红阻断：
```text
ops/           # 内部运维脚本路径
alioth         # 物理机硬件代号
K40 / k40      # 手机设备型号
termux / Termux# 宿主软件名
proot / PROOT  # 容器软件名
container      # 容器设施名词
server         # 服务器设施名词（改为“分析工作台/分析流水线”）
127.0.0.1      # 本地私有 IP
10022 / 8022   # 内部转发端口
```

### 3. 脱敏契约测试守卫（`tests/report_redaction_contract.test.js`）
该测试对 `local_projects/` 下全部 HTML 报告执行真实验收：
- 自动剥离内嵌的 Base64 图片载荷（防止随机字符误命中）；
- 正则检索全部黑名单词汇；
- 实测现状：**3/3 测试全绿通过，脱敏合规率 100%**。

## 三、数据存储拓扑与流转规范

```text
[K40 远端 SSD 计算区: /mnt/ssd/bio_data/projects/<项目>/line3_spatial/]
├── raw_data/                 # 原始芯片输入文件 (tissue_positions.csv, filtered_feature_bc_matrix.h5)
├── processed/                # 中间产物 (spatial_qc.h5ad, spatial_norm.h5ad, spatial_domains.h5ad)
├── results/                  # 结构化表格 (moran_i.tsv, deconv_proportions.tsv, markers.tsv)
└── figures/                  # 远端渲染的原生 300 DPI PNG 图件
       │
       ▼ 经 server/proc.js (scp 接缝) 自动回搬
[本地 PC 产物区: local_projects/<项目>/]
├── figures/line3_spatial/    # 回搬的本地图件镜像（带 manifest 溯源）
└── report/                   # 由 ops/report_render_html.py 编译的独立单文件 HTML 报告
```
