## 一、用户裁定（2026-11-15，方案依据）

1. 控制端做成**绿色免安装桌面软件**，双击即用，单管理员自用，不开浏览器操作。
2. 对外只暴露**客户填单 Web**，内网穿透由用户自行完成；服务端与算力面永不出公网。
3. 两面之间只靠 **PKG 工单包**这一单向载体连接（收件箱真源 `portal/inbox/PKG_*/` 不变）。
4. 部署形态按 **A 方案**执行：填单 Web 与收件箱同机（D2.3，2026-11-15 补充裁定）。
5. PKG 回传走**自动推送**：portal 侧经既有 sync 协议出包，本地轻量接收器消费，
   到包即触发收件箱落盘（D2.3，2026-11-15 补充裁定）。
6. 客户访问凭证采用**白名单文件**制：管理员在 `whitelist.md` 录入凭证，portal 热加载；
   每个凭证映射客户身份，进入 PKG 留痕（D2.3，2026-11-15 补充裁定）。

## 二、AIM

**把两条已验证链路收口成两面产品形态：客户在外网填单落包，管理员双击 exe 在软件里收发工单、控制算力、导出结果，全程不碰命令行与浏览器。**
