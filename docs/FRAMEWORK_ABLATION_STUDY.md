## 五、结论
- 承重组件（消融后捕获率下降）：双射定律1 目录同源、双射定律2 依赖闭包422、双射定律3 计划恒等、图件调度准入（R75）。
- 单层冗余但集体承重（单消融0损失、组消融有损失）：源码审计器 C1-C14、第20道门禁 figure_code_gate、样式契约测试（≥8pt）。
- 多层覆盖缺陷（冗余设计）：D1、D2。
- 独立承重（每组件捕获唯一缺陷类，不可替代）：门户双射定律1/2/3 + 图件调度准入，分别守卫目录同源/依赖闭包/计划恒等/图件前置，消融任一即漏一类缺陷。
- 设计判定：框架无无效组件。字号层为有意的 Defense-in-Depth（三组件覆盖 D1/D2，组消融损失 33.3%）；双射层为独立承重（各组件边际贡献 16.7%）。
