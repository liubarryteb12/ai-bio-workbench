# L3 单切片 A/B：200 µm 截断与 BANKSY 平滑（2026-11-06）

结论先行：**2.1（200 µm 截断）记入不做清单**，理由是实测近乎无操作；
**2.2（邻域平滑）只在 λ=0.2 且仅用于空间域聚类时可选采纳**，标记保持率 94.9%。

## 一、实验设置

| 项 | 值 |
|---|---|
| 切片 | `C1-D7`（本数据集 spot 数最多，2596 个） |
| 种子 | 42 |
| 邻接图 | 逐切片像素 kNN，k=6，对称化 |
| 数据 | `spatial_domains_mouse.h5ad`（已归一化，未平滑） |
| 聚类 | PCA(30) + KMeans(k=9)，raw 与平滑用同一算法，保证可比 |

## 二、像素到微米换算：两条路径差 20%

| 路径 | 换算 | 200 µm 对应 |
|---|---|---|
| `scalefactors.spot_diameter_fullres = 87.22`（按 Visium 标称点径 55 µm） | 0.6306 µm/px | 317 px |
| 六边形晶格中心距按标称 100 µm 反推（实测最近邻中位 132 px） | 0.7576 µm/px | 264 px |

两条路径比值 **1.201**，即 20% 偏差。任何以微米为单位的阈值都必须先解决这个偏差，
否则「200 µm」到底是 264 px 还是 317 px 说不清。

本轮的缓解：两个换算下的截断阈值都远大于最近邻距离（132 px），所以结论对该偏差不敏感。

## 三、2.1 200 µm 物理距离截断：近乎无操作

| 指标 | 基线 k=6 | 加 200 µm 截断 | 判据 |
|---|---|---|---|
| 边数 | 15966 | 15962 | 剔除率 0.03% |
| 剔除率 |  | **0.03%** | 期望 1%~5% 才说明真的砍掉了跨裂隙伪边 |
| 孤立 spot | 0 | **0** | 要求 < 2%，满足 |
| Moran I 最大变化 |  | **0.0002** | 排序几乎不变 |

判定：剔除率 0.03% 远低于 1% 的信号门槛，等于没动。原因是该切片 spot 密集（最近邻 132 px），
k=6 的邻居本来就都在 200 µm 内，没有长程伪边可砍。

**决定：不采纳。** 采纳它只会增加一处配置与一段换算逻辑，换不来任何可观测收益。
如果将来遇到撕裂切片，再按当时的实测数据重新评估。

## 四、2.2 BANKSY 式邻域平滑：有效但有代价

平滑公式：`X_s = (1-λ)X + λ·W_norm·X`，`W_norm` 为对称化后行归一化的 kNN 邻接。

| λ | 空间同质率 | 相对基线 | 域 marker 与 λ=0 的 Jaccard |
|---|---|---|---|
| 0.0（基线） | 0.8157 |  | 1.000 |
| 0.2 | 0.8379 | **+0.0222** | **0.949** |
| 0.4 | 0.8642 | +0.0485 | 0.766 |
| 0.6 | 0.8840 | +0.0683 | 0.770 |
| 生产域标签（参考） | 0.8681 |  |  |

读法：平滑确实提高空间同质性，但 λ≥0.4 时域 marker 只保留约 77%，属于「把稀有微区抹进主域」的征兆。
λ=0.2 是唯一同时满足「同质性上升」与「marker 基本不变（94.9%）」的取值。

**决定：可选采纳 λ=0.2，且只作为空间域聚类的输入特征。**
铁律：平滑矩阵不得用于 NNLS 解卷积、Moran I 计算或靶基因表达量报告，
否则等于用平滑后的数据重复计算空间自相关，属循环论证。

### BANKSY 合入约束（Argon 定的三条铁律）

1. **默认态零漂移**：`--banksy-lambda` 缺省 0.0，平滑算子完全旁路，
   存量基准项目输出必须逐字节可复现（md5 不变）。
2. **只在降维空间平滑**：HVG2000（上游已保证）→ PCA30 → 在 30 维上做
   `Xs = (1-λ)X + λ·W_norm·X`。严禁回全基因 21318 维：稀疏矩阵会稠密化，
   多切片时在 8GB 设备上必 OOM。
3. **只写 obsm 不碰 adata.X**：平滑结果进 `obsm['X_banksy_pca']`，
   进/出用 `ops/matrix_guard.py` 指纹断言；下游 Moran's I 与 NNLS 解卷积
   一律读原始矩阵，否则构成循环论证。

### 孤立点的特殊处理

度数为 0 的 spot 没有邻居可借，`(1-λ)X` 会把它们整体收缩到 0.8 倍，
等于凭空改变这些点的坐标，下游聚类会把它们单独聚成一类假域。
因此平滑后必须对孤立点回填原始 PCA 值，并在报告里记录 `banksy_isolated_spots`。
