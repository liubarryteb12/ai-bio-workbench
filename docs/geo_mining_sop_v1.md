## 全局硬约束（违反任一条，该层输出作废，不许往下走）

**C1 方向红线**：全程非肿瘤、非免疫。判定用三重判据——疾病名称、被解析的细胞/分子对象、结论主轴，三者均不得落在肿瘤或免疫学范畴。疾病中出现炎症相关通路可接受，但禁止把免疫细胞亚群浸润、免疫微环境分型作为核心结论或核心论证环节。

**C2 溯源红线**：任何进入结论的数字，必须能追溯到「数据集 GSE 编号 + GPL 平台 + 样本 GSM 列表 + 分析参数」。禁止给出无法溯源的结果。

**C3 阈值显式化红线**：差异分析阈值、质控过滤规则、软阈值、随机种子、R/Python 包名与版本号，全部必须写明具体值，禁止写"使用常用参数""按默认设置"。

**C4 数据泄露红线**：机器学习特征筛选、标准化、阈值调优只能在训练集内部完成（嵌套/重复交叉验证），严禁在全量数据上先筛特征再拆分训练/验证集。

**C5 不编造红线**：拿不到的原始数据、不确定属于哪一组的样本、无法确认的分组定义，一律标注为「⚠️未确认」并向用户提问，禁止用推测填充分组标签或样本数。

**上下游逻辑总纲**：科学问题决定分组怎么切 → 分组决定设计矩阵 → 设计矩阵决定批次校正的写法 → 批次校正与阈值决定差异基因 → 差异基因加表型决定模块与特征基因 → 特征基因决定模型 → 模型必须有独立外部数据才能成立 → 干湿衔接决定结论层级。任何一环没写清，污染会顺着这条链往下传。

## Stage 0 · 科学问题与课题定型

**输入**：用户给出的疾病/表型方向（若未给出，先问，不要自行选题）。

**动作**：
1. 把方向收敛成一句可检验的科学问题，结构为「在【疾病】的【组织/细胞层面】中，【分子事件】与【表型/分期/疗效】是否存在可被转录组数据捕捉的关联」。
2. 写出假设链条：表型 → 分子读出 → 可用数据形态 → 需要的样本分组。
3. 明确结论上限：只到"候选 biomarker"，还是要到"机制 + 功能验证"。这决定要不要走 Stage 9。

**产出**：科学问题 1 句 + 假设链条 3–5 步 + 结论上限声明。
**验收（卡点）**：该问题必须能指出"用什么分组比较来回答"；说不出分组比较的，退回重写。

## Stage 1 · GEO 元数据审查与准入

先固定数据结构（后续所有表格的字段基准）：

| 层级 | 编号形式 | 存放内容 | GEO 上的落点 |
|---|---|---|---|
| Series | GSE#####, GDS#### | 研究级元信息、平台引用、样本清单 | GSE#####_series_matrix.txt.gz |
| Platform | GPL### | 探针/注释定义（probe→gene） | GPL#####_annot.gz / soft 文件 |
| Sample | GSM### | 单样本数据与表型注释 | series_matrix / soft 的 !Sample_* 字段行 |
| 关系 | GSE 1─N GSM，GSE ─N GPL | 一个 GSE 可多平台，一个 GSM 只属一个 GPL | 多平台 GSE 常见（芯片+RNA-seq 同研究） |

**动作**：对每一个候选 GSE 建立审查表，字段固定为：

`GSE编号 | 标题 | 物种 | 平台GPL编号(全部) | 数据形态(芯片/RNA-seq/miRNA/snRNA-seq) | GSM总数 | 每组样本数 | 疾病本体 | 组织/细胞类型 | 分组变量 | 是否有raw文件 | supplementary文件清单 | 是否肿瘤 | 是否免疫(三重判据结论) | 发表/引用文献 | 准入结论(用/部分用/弃)`

**准入判定顺序（先淘汰再分析）**：
1. **疾病本体校验**：疾病必须属于代谢病、神经退行、心血管、退行性/纤维化、遗传血液病等非肿瘤非免疫范畴。
2. **研究对象校验**：若被研究的细胞对象本身是免疫细胞（如树突状细胞、巨噬细胞极化），即使疾病是心血管病，也判为不合格并剔除。
3. **结论主轴校验**：若文献结论落在免疫治疗靶点或发表于免疫学期刊，判为不合格。
4. **可用性校验**：样本量、分组可重建性、raw 可得性（Stage 3）。

**产出**：GSE 审查表 + 每个数据集的准入结论与理由（剔除必须写理由，不能静默删除）。
**验收（卡点）**：
- 每组样本数 n ≥ 3；某组 n < 3 → 标记为「低证据组」，禁止用于差异分析主结论，只可做探索。
- 疾病组与对照组样本数严重失衡（如 3 vs 30）→ 必须声明后续建模的抽样与加权策略。
- 同一 GSE 内混有多个组织部位 → 未拆分组织前不得合并分析。

## Stage 2 · 实验设计解析与"有用部分"提取

**动作 1：从 GEO 文件里把分组读出来，而不是从标题猜。** 必须落到字段：`!Sample_title`、`!Sample_source_name_ch1`、`!Sample_characteristics_ch1`（最关键字段，常以 disease:/treatment:/cell type:/age/sex/tissue 形式给出真正分组变量）、`!Sample_geo_accession`、`!Series_platform_id`、soft 文件（更完整备选）、`!Sample_supplementary_file`（raw 链接）。

**动作 2：重建分组表（Design table）**，字段固定为：
`GSM | sample_title | disease_status | tissue | cell_type | stage_or_timepoint | treatment | sex | age | batch/source | platform_GPL | 归入组别 | 判定依据(哪个字段)`

**动作 3：按科学问题切子集，留剔除日志。**
- 只保留能回答 Stage 0 问题的比较对，无关处理组显式剔除并写明理由。
- 多因素设计（组织 × 疾病 × 时间）优先切主效应可识别子集；切不出来改用含交互项的设计矩阵而不是丢弃。
- 多个独立小样本亚组默认分别分析后 meta 合并，不直接合并样本（合并把亚组间差异吸收进批次）。

**动作 4：混杂与批次识别**——列出所有非研究兴趣但造成分层的变量（实验室、制样日期、平台、性比/年龄差、合并用药），逐个判定：可校正 / 只能亚组分析 / 无法处理（则该数据集弃用）。

**产出**：分组表 + 子集切分方案 + 剔除日志 + 混杂处理决策表。
**验收（卡点）**：
- 分组表每行都要写判定依据来自哪个字段；靠猜的样本数超过总数 10% → 退回确认，禁止继续。
- 疾病组与对照组性别、年龄分布差异明显时，必须在设计矩阵里纳入为协变量，否则卡住。

## Stage 3 · 原始数据获取与对齐

**动作 1：判定 raw 还是 processed（分层规则，2026-10-20 裁决）**——raw 可得**且容器工具链支持** → raw 优先；raw 不可得或处理工具链不支持 → 用处理级数据并**显式声明处理层级与上游软件**。两类情形都必须在报告里写明选了哪条路。

| 数据形态 | raw 是什么 | 若拿不到 raw 的替代方案 |
|---|---|---|
| 芯片（Affymetrix） | .CEL 原始强度 | 用 GPL 注释把 probe 级信号映射到基因，声明"探针级处理数据" |
| RNA-seq | counts 矩阵 | 回 SRA/ENA 自行比对定量，需说明流程与版本 |
| miRNA | 成熟 miRNA 计数/信号 | 用 GPL 注释映射 miRBase ID |
| 单细胞 | matrix.mtx / 10x 三件套 / h5ad | 声明处理层级与上游比对软件版本 |

**动作 2：ID 层对齐**（多数据集合并前置条件）：统一到同一基因 ID 层（推荐 HGNC symbol，或 org.Hs.eg.db 做 ENTREZID）；probe→gene 以对应 GPL 注释为准，多 probe 折叠规则（最高表达探针/均值）必须写明；多 GPL 合并先统计基因交集，交集过小的数据集不进合并池，改独立分析后 meta。

**动作 3：样本 manifest 一致性校验**：矩阵列数 = 分组表行数 = GSM 数；列名与 GSM 一一映射；无重复列、无全零/全 NA 列；分组表每一组在矩阵里都有对应列。

**产出**：raw 或处理级矩阵 + ID 映射日志 + manifest 校验结果（逐项通过/失败）。
**验收（卡点）**：manifest 任一项不通过 → 停止分析，先修数据对齐，不得"先跑起来看看"。

## Stage 4 · 质控、标准化与批次校正

**动作 1：按形态分流的质控与标准化**
- 芯片：分布检查 → RMA/分位数标准化 → 低表达过滤。
- RNA-seq：低计数过滤（写明规则与保留基因数）→ limma::voom 或 DESeq2 sizeFactor / edgeR TMM。
- miRNA：同 RNA-seq，注意发夹/成熟体 ID 去重。

**动作 2：批次校正（最容易毁掉课题的一步）**
- 工具：sva 的 ComBat / ComBat_seq（counts 版）。
- 硬性纪律：设计矩阵 mod 必须保留生物学分组变量，批次变量为 batch。把疾病状态当批次校正掉，差异信号会同消失。
- 校正前禁止合并数据集；校正后必须做前后对比证明"批次缩小、分组信号仍在"。
- 有无法校正的结构性混杂（如某数据集只有疾病组）→ 该数据集不进合并池，只做外部验证集。

**产出**：净化后表达矩阵 + 校正前后 PCA 说明 + 每步样本数/基因数变化日志。
**验收（卡点）**：必须有校正前后分组样本分布图；分组方向在校正后完全消失 → 判定过度校正，回动作 2 改设计矩阵。

## Stage 5 · 差异表达与功能富集

**动作**：
- 工具按形态选：芯片 → limma；RNA-seq → DESeq2（或 edgeR）；合并后 → "合并 + 批次为协变量"的模型，不是各自跑完取交集（除非明确做 meta）。
- 阈值写死：|log2FC| ≥ 1 且 padj ≤ 0.05（BH）。若改成 p.adj < 0.05 不限 FC，必须显式声明是敏感性分析。
- 富集三层：GO（BP/CC/MF）+ KEGG → clusterProfiler；GSEA 用全基因排序（不只 DEG，避免阈值偏倚）；GSVA/ssGSEA 样本级通路评分（接 Stage 8）。基因集来源与版本号写明。
- **非免疫方向重点**：富集结果若主要落在免疫细胞活化/趋化/抗原呈递通路 → 说明该数据集或方向上免疫信号占主导 → 需要重新界定科学问题（转向实质细胞功能、代谢、基质重塑、蛋白稳态、线粒体功能），不要顺着免疫通路滑下去。

**产出**：DEG 表（含方向）、富集表、GSEA leading edge、火山/热图。
**验收（卡点）**：DEG 为 0 → 检查阈值与分组方向；DEG 异常大（>50% 基因）→ 检查分组是否混入批次/组织差异。

## Stage 6 · WGCNA 共表达网络与表型关联（line1 专属）

**动作**：goodSamplesGenes 预处理、离群剔除并记录；软阈值写明确定方法（scale-free R² 目标，通常 ≥0.8）与最终 power；minModuleSize/deepSplit/合并阈值写明；模块-性状相关给出 r 与 p；hub = 模块内连通性（kME）× 性状相关性双重排序。保留的模块必须与实质细胞功能或退变/代谢表型相关，不是与免疫浸润程度相关。

**产出**：聚类树+模块色条、模块-性状热图、hub 清单。
**验收（卡点）**：软阈值 R² < 0.8 → 明确声明拓扑模型不适用并改用其他共定义方法，禁止强行套 WGCNA。

## Stage 7 · 机器学习特征筛选（多算法取交集，line1 专属）

**动作**：
- 先拆数据再筛特征（C4）：划分训练/测试集（写明比例与分层方式），记录 set.seed()；所有算法仅在训练集拟合。
- 多算法并行：glmnet（LASSO，lambda 选择规则写明 1se 或 min）、SVM-RFE（kernlab）、随机森林（重要性指标写明）、XGBoost（树深/轮数/重要性口径写明）。
- 取交集：交集为空按顺序兜底并写明规则——① 放宽单算法阈值 ② 取至少 3 种算法命中的并集 ③ 用 Stage 5 与 Stage 6 的 DEG∩hub 作候选池再筛。
- 报告每个算法各自特征数与交集特征数，不许只给最终清单。

**产出**：各算法结果表 + 交集特征基因 + Venn/热图。
**验收（卡点）**：出现"全量数据上筛完特征再分训练测试"→ 方法学缺陷，本层作废重做。

## Stage 8 · 建模、评价与外部验证（line1 专属）

**动作**：
- 建模：多因素 Logistic 回归（因变量编码写明）+ Nomogram（rms）。有分期/预后需求改 coxph/timeROC 并声明终点。
- 评价三件套必给：ROC+AUC（训练/验证分别给）、校准曲线、DCA。
- 外部验证：必须独立数据集（不同 GSE，理想不同 GPL/队列）。写明验证集 GSE、样本数、分组；验证集内不得重新拟合模型参数。
- 保守性检查：特征基因逐个单基因 ROC，与模型整体 AUC 对比，说明组合增益来源。

**产出**：模型公式、系数表、ROC/AUC/校准/DCA 图、外部验证结果表。
**验收（卡点）**：无独立外部验证 → 结论上限自动降为"候选标志物，未泛化验证"，结论里明写，不允许表述为"诊断模型"。

## Stage 9 · 干湿衔接（可开关模块）

**开关 = 开（目标二区及以上）**：表达层 qPCR（引物设计、内参、统计、生物学重复 n≥3）+ Western Blot；功能层 siRNA/shRNA/过表达/CRISPR 干预 + 表型读出（按疾病实际表型选，不套肿瘤套餐）；调控层双荧光素酶（miRNA-lncRNA/TF-靶轴）；可选动物模型 + 干预疗效。

**开关 = 关（纯生信，工作台默认）**：必须补替代强度——跨多个独立 GSE 的重复验证 + 单细胞层面定位（核心基因在哪些实质细胞表达）+ GSVA 通路活性与表型相关；并在限制部分明写"未经实验验证"。

**产出**：验证清单（每项：目标基因 × 方法 × 预期结果 × 样本数）或替代论证方案。

## Stage 10 · 非肿瘤非免疫专用替代论证层（核心特色）

主流模板的免疫浸润在此整体替换为下列至少两条组合，替换理由必须写明：

| 替代维度 | 具体做法 | 工具 |
|---|---|---|
| 实质细胞定位 | 核心基因在实质细胞类型中的表达特异性 | Seurat/Scanpy 注释 + marker；SingleR/Azimuth |
| 细胞类型去卷积 | bulk/空间信号拆到组织 resident 细胞组成 | cell2location/RCTD/SPOTlight（需参考） |
| 代谢与蛋白稳态 | 代谢通路活性评分 | scMetabolism、GSVA（KEGG 代谢集） |
| 基质重塑/退变 | ECM、MMP/TIMP 平衡、蛋白酶降解轴 | clusterProfiler + 自定义基因集（写明来源） |
| 线粒体/氧化应激 | mtDNA 编码基因比例、呼吸链复合体评分 | 自写评分脚本（参数写明） |
