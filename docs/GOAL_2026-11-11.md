## 一、AIM（总目标）

### 1.1 北极星（一句话）

**在不更换状态模型的前提下，把「自己造」换成「买成熟轮子」，让已经写出来的控制面收口成可提交、可讨论、可对外交付的基线。**

具体到三件事：把 174 个在途文件变成可回滚的提交；给 AI 与人工两个 HTTP 写者加上单权威租约；把已有的磁盘队列用买来的存储和契约反证变成受控队列。

### 1.2 三条硬约束（不因进度让步）

1. **真源不变**：`work_order/v2` 为正式输入，`receipt/v1` 为唯一权威回执，五态状态机、11 层判定链、`ledger/` 永久追加写、`SCOPE.md` 12 条 REJ 一律不动。买来的组件只能躲在既有契约后面。
2. **门禁不放宽**：既有门禁的顺序与判据不得改宽松换绿。新增组件必须先写会红的契约测试，再写实现。
3. **一次只换一个组件**：每次引入单独成提交，可回滚；不打包换轨。

### 1.3 硬筛子：绿色便携包

交付形态是**单目录自足运行**。任何要求常驻服务端的组件（Redis、Postgres、Temporal）默认进不来；单二进制与纯 npm 库可以进。这一条决定了 `BullMQ + Redis`、`Temporal/Restate` 的裁定是「退」，而 `better-sqlite3`、`Caddy` 是「收」。

### 1.4 完成判据（DoD，可机检）

| # | 判据 | 验证方式 |
|---|---|---|
| 1 | 工作树干净，在途变更按主题全部提交 | `git status --porcelain` 无非预期输出 |
| 2 | AI 与人工并发改状态被单权威租约拦住 | `authority_lease_gate` 绿，且变异反证 `escaped === 0` |
| 3 | 队列重启不丢、单消费者、终态重跑被拒、回执不重复 | `work_order_queue_gate` 绿，且变异反证 `escaped === 0` |
| 4 | 上传前端具备断点恢复与重试，服务端契约不变 | Playwright 续传用例绿，`upload.js` 旧测试不退化 |
| 5 | 门禁总数 25 → 27，测试数与基线一致 | `metrics_sync.mjs --check` 通过 |
| 6 | 便携包同源、可重建 | `dist_parity_gate.mjs` 分叉与缺失为 0 |
| 7 | 三件套全绿 | `npm test`、`npm run test:e2e`、`run_all_gates.mjs` 全量 |

### 1.5 明确不在本目标内的事

第二条算力节点、公网交付形态（除可选票）、65 个 Draft 图件孵化、`OnboardingView.tsx` 拆分、历史 13 个项目目录迁移。这些另立票，不混进控制面收口。
