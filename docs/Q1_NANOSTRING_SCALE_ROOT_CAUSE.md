# Q1 更正：NanoString 的问题不是 trend 参数，而是输入尺度

## 一、结论先行

我上一轮给 Argon 的 Q1 判断是**错的**。我说「min_padj=0.869 无显著基因，是
`eBayes(trend=TRUE)` 在 NanoString 计数值域上过度保守」，建议评估 trend 参数。

实测推翻了它：

| 试验 | min_padj | n_padj<0.05 | max\|log2FC\| |
|---|---|---|---|
| `trend=TRUE`（现状） | 0.869225 | 0 | **15,113** |
| `trend=FALSE` | 0.936853 | 0 | 15,113 |

**关掉 trend 反而更差。** 所以问题不在 trend。

真正的病灶是**输入尺度**：这份 series_matrix 是**原始计数**（min=0, max=119,391, median=275），
而 limma 的 `lmFit`/`eBayes` 假定输入已是 log2 尺度。

| 试验 | min_padj | n_padj<0.05 | max\|log2FC\| |
|---|---|---|---|
| 原始计数直接喂 | 0.869225 | 0 | **15,113**（荒谬） |
| `log2(x+1)` 后喂 | **0.582695** | 0 | **2.47**（合理） |

logFC 量纲从 15,113 降到 2.47，两者差 6,000 倍。原始计数被当成 log2 值时，
「logFC」实际等于「两组计数的差值除以基线」，完全不是倍数的对数。

## 二、`deg_limma` 的真实缺陷

原实现只校验：首列是 gene、样本集一致、无 NA、两组、每组 >= 2 例。
**完全不检查尺度。** 于是原始计数会被静默当作 log2 值处理，产出一个量纲荒谬的结果，
而流程会「成功」退出。

## 三、修复：尺度守卫

在 `deg_limma` 加一条判据，用**上四分位数**：

```r
q75 <- as.numeric(quantile(mat, 0.75, na.rm = TRUE))
if (q75 > 50) fail("表达矩阵疑似未经 log 变换…")
```

为什么用上四分位数而不是中位数或最大值：
- log2 尺度的表达矩阵，上四分位通常是个位数到十几；
- 原始计数即使不深，中位数也常在上百；
- 上四分位比中位数更靠上，但它 > 50 在两种尺度上是清楚的分界，且不会被个别离群高表达基因拉偏。

## 四、真机验证（两个方向都测）

| 场景 | 结果 |
|---|---|
| GSE316126 原始计数（q75=1004） | `REAL_EXIT=1`，报错指名「疑似未经 log 变换」 |
| DCM 基准（已 log2） | `DCM_EXIT=0`，且诊断数值完全不变（cohort_suspect=17,982 / sig_before=3,649） |

**没误伤既有数据**，这是这条守卫能上线的前提。

## 五、对 Q1 选项的影响

我原先给 Argon 的三个选项（A 不做 / B 加 --no-trend 开关 / C voom 适配）**前提就是错的**，
因为 trend 不是病灶。

正确的选项应该是：

- **A（已实施）**：加尺度守卫，让原始计数**无法**被静默喂进 limma。这是防御性的，
  不改任何现有行为，只拒绝错误输入。
- **B**：给 `deg_limma` 加可选的 `--log2-transform` 开关，输入原始计数时自动做
  `log2(x+1)`。但这有风险：自动变换会掩盖上游该做归一化的问题，且 NanoString 更适合
  `vsn`/`RCC` 内参校正而非简单 log。
- **C**：把 NanoString 作为独立平台分支，走专门的归一化流程（需评估 `vsn` 或
  `NanoStringNorm`），工作量大。

**建议 A + C**：A 作为立即生效的守卫（已做），C 作为若真要纳管该平台时的正解。
不做 B，因为静默变换会掩盖上游问题。

## 六、附带发现

即便做 log2 变换，min_padj 仍是 0.583，**没有任何基因达到 0.05**。这说明：
- 782 基因面板 + n=12/组，对 PBMC 这种细胞组成异质性高的样本，统计功效确实不足；
- 或 T2D vs Control 在 PBMC 转录组层面本就没有强信号（临床上 T2D 是代谢病，
  外周血转录组变化可能确实微弱）。

**这是生物学的合理结果，不是流程故障。** 该数据集作为「队列诊断列的对照实验」的使命已完成
（320 倍特异性验证），继续深挖它的差异基因没有意义。
