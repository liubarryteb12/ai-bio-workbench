三、 核心防崩算法、数学守恒公式与生产级架构骨架

1. 图像非空白像素方差校验公式（防退出码 `1` 坏图落盘）：
设渲染输出的 RGB 像素通道采样序列为 $X = \{x_1, x_2, \dots, x_N\}$，均值 $\mu = \frac{1}{N}\sum_{i=1}^N x_i$，像素方差定义为：

$$\sigma^2 = \frac{1}{N}\sum_{i=1}^N (x_i - \mu)^2$$



当 $\sigma \le 10^{-4}$ 时，判定为全白或全黑空白废图，立即物理删除残缺文件并返回退出码 `1`。

四、 跨模块 `CapabilityBus` 只读联动接口契约
底座提供全局唯一 `CapabilityBus`：

* 注册签名：`registerCapability(providerModId: string, contract: CapabilityContract): ExitCode`
* 查询签名：`query<TReq, TRes>(capabilityId: string, request: Readonly<TReq>): Promise<{ exitCode: ExitCode; data?: Readonly<TRes> }>`
* 保护机制：查询结果返回前强制执行递归 `Object.freeze`，任何下游调用方尝试原地篡改返回属性将直接触发编译期与运行期双重阻断。
